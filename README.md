# Atividade Avaliativa 2 — Java

Conjunto de exercícios desenvolvidos em Java para praticar fundamentos de programação, validação de entradas, estruturas condicionais e estruturas de repetição.

## Conteúdo

Os exercícios estão em `atividade_avaliativa2/src/`:

- `Q1_numeros_0a10_verif.java`
- `Q2_senha_usuario.java`
- `Q3_validacao_informacao.java`
- `Q4_populacao_AB.java`
- `Q5_crescimento_populacao.java`
- `Q6_1a20_abaixo.java`
- `Q6_1a20_aolado.java`
- `Q7_maior_numero.java`
- `Q8_soma_media.java`
- `Q9_1a50_impares.java`

## Tecnologias

- Java
- Aplicações de console
- `Scanner` para leitura de dados

## Como executar

Cada arquivo possui seu próprio método `main`. Exemplo:

```bash
cd atividade_avaliativa2
javac -d out src/Q1_numeros_0a10_verif.java
java -cp out Q1_numeros_0a10_verif
```

Para executar outro exercício, substitua o nome da classe no comando.
